# BumpRace for GFOS

The AmiCradle Team's port of BumpRace (Karl Bartel's 2D gravity racer:
steer a racer through cave tracks against the clock, without touching the
walls) to GFOS: AmigaOS 3.2 with GFOpenUp, 68040/68060 + FPU, on
GFOpenUp's SDL 2. It ships as a release archive with an Installer and as
the GFOpenUp part Parts/BumpRace.

Upstream (code and data) is fetched at build time (package/bumprace.lock);
this repository holds only the Amiga port. See [AMIGA_PORT.md](AMIGA_PORT.md).
